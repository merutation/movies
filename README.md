# Movies

A simple Android app built with Jetpack Compose that displays a list of movies, filterable by genre, with a detail screen for each film.

## Features

- Scrollable movie list with genre filter chips (`LazyRow` + `LazyColumn`)
- Navigation between list and detail screens (Navigation Compose)
- Material 3 theming with `Scaffold` and `TopAppBar`
